## Direct refresh / integration path

`cinema/scripts/refresh-direct-official-sources.mjs` was added to refresh MUVIE Songren and Eslite without GitHub Actions. Its intended behavior is:

1. fetch selected official sources directly;
2. keep last-known-good rows when one source fails;
3. replace only rows belonging to a successfully refreshed source;
4. merge into the normalized Taipei date/city chunks;
5. reuse BAMID cinema IDs and the shared movie catalog;
6. prefer direct official evidence over manual snapshot or aggregator duplicates;
7. update source health, cinema `recommendation_eligible`, manifest coverage, and provenance;
8. never expose upstream schedule APIs to site visitors.

The script supports `--dry-run` and source-scoped refreshes. GitHub Actions are not required.

At the time of this note the code path is committed, but the saved static showtime chunks have not yet been regenerated by this direct script. Do not claim the new MUVIE/Eslite rows are live in the public static dataset until a direct refresh is executed and the resulting JSON diff is verified.
